BUILD-YOUR-OWN-AI-HELPER PACK
============================
1. SCHEMATIC.md - what I am, layer by layer
2. TOOLS-REFERENCE.md - every capability I have, with usage recipes
3. SKILLS-CATALOG.md - my specialist knowledge modules
4. CAPABILITIES-CHECKLIST.md - what I can/can't do + quotas
5. BUILD-YOUR-OWN-AGENT.md - how to build one like me (or better)
6. code/ - a WORKING starter agent generator (copy main.pjs + index.html into a new generator and it runs)

Honest note up front: this pack cannot contain my model weights - nobody outside the lab has those.
What it CAN give you is everything else: the harness architecture, the tool loop, the skills,
and a runnable agent that uses the same AI backend I use. The model is the engine; this is the car around it.
